; glyph-patterns.txt - THE PATTERNS A MATERIAL CAN PRINT. engine/glyph/patterns.hpp reads
; it, and a material asks for a pattern by the name given here.
;
; DRAW A PATTERN, DON'T DESCRIBE IT. One block per pattern:
;
;     pattern <name>            a-z, 0-9, - and _ ; `none` is taken
;     <the rows, exactly as they should look>
;     end
;
; - Inside a block every character is a glyph except a SPACE, which is an empty
;   cell - so text copied out of a pattern generator pastes in untouched. A `;`
;   inside a block is a glyph too; comments go between blocks.
; - Short rows are padded with empty cells, so an editor trimming trailing spaces
;   does not change a pattern.
; - The block is ONE TILE and it repeats over each face of the costume. Its top row
;   is the top, and its middle sits on the middle of the body, so a big block pasted
;   whole shows its centre rather than a seam.
; - `pattern <name> scatter` starts every face at its own place in the tile. Use it
;   for random noise; leave it off for geometry, so the chest and yoke line up.
; - Only code page 437 can be drawn - ASCII plus ░▒▓ █▄▀▌▐ ─│┌┐└┘├┤┬┴┼ ═║╔╗╚╝╠╣╦╩╬
;   and the rest of the IBM PC set. Anything else is refused with its line and column.
; - A tall region draws each cell twice as high as it is wide, the shape pattern
;   sites draw for; square is 1:1. That is the look's `cell`, not the pattern's.
;
; SOURCES: patterns generated with an online ASCII-art pattern maker (its output is
; free to use, no attribution needed) and generic motifs. No signed gallery pieces.

; ---- the prototype's B look, as tiles ----
; Generated once from B's glyph sets at its 80% density - random, so `scatter`.
